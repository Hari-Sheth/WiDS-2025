# WiDS-2025

Repository where I store all the work I did and learnt during WIDS '25

## Overview
The project aimed at creating a Deep Learning model for Image Deblurring, starting from the basics of Neural Networks and the introduction to necessary Python libraries, and gradually proceeding towards the more advanced concepts of Convolutional Neural Networks and Generative Adversarial Networks.

## Folders

### notebook
Stores all the .ipynb files of my work, organized by week.

### datasets
The folder structures of the datasets, fetched by tree command.
